Bootstrap

Δi＝装着i−非装着i。この研究なら、14人のペアから重複を許して14人分を再抽出し、同じ統計量を再計算します。10歩を独立な人として増やしません。

対象統計量、Percentile／BCa等のCI法、反復回数、乱数設定、CIの端の安定性を確認。反復を増やしても元標本の情報量は増えず、小標本の問題が消えるわけではありません。

別の患者で再現した証拠ではなく、既存標本に基づく推定の揺れの情報です。[HB][SCB]

Leave-one-participant-out

14人なら1人のペアを外した13人で同じ解析を14回。全員を含めた結果と、除外ごとの効果・相関・CIを比較します。

1人外すとp≥0.05になっただけで不安定とはしません。 効果の方向と大きさがどう動いたかを優先。ここでの目的は影響度評価であり、予測モデルの交差検証とは区別します。

モデル・前処理への感度

筋力・付着位置・力伝達の仮定、フィルタ、接地閾値、周期窓、欠測処理などを、根拠のある範囲で変更します。

効果の方向・大きさ・不確実性を主解析と並べて確認。「頑健だった」という一言でなく、どれくらい変わったかを見ます。[H15]

何が不足しているかも分ける

Bootstrap CI＝標本の不確実性。モデル設定の最小～最大＝設定への感度。新たな参加者での結果＝別標本での検証。これらは同じではありません。

提示された本文で追加解析が確認できなくても、補足資料が未確認なら、そのことを記録します。未実施と決めつけません。[添付論文 pp.4–5,10]

「頑健」の範囲を明記：【参加者の再抽出／1名ずつ除外／設定変更】に対して、【方向・大きさ・不確実性】は保たれた。ただし【未検証の要因】に対する頑健性は不明。

    真の現象 → 測定 → 標本抽出 → 前処理 → モデル → 推定結果 → 解釈

    妥当性評価は、この途中のどこかで生じた歪みを「現象そのもの」と取り違えていないかを確認する作業です。各チェック項目の下に、なぜ必要か／未評価・誤設定だと何を真実と誤認するかを併記しました。

    ① 前提・入力妥当性

    その手法が想定するデータ構造になっているか。

    • 尺度・分布・独立性・欠測
      なぜ必要？観測単位同士の依存を正しく扱わないと標準誤差や帰無分布が成立しないため。誤ると相関した観測を独立な追加情報として数え、精度を過大評価して偽陽性を増やす。
    • 外れ値、測定誤差、標準化
      なぜ必要？距離・分散・正則化は変数の単位に影響されるため、尺度の寄与を意図通りにする必要がある。誤ると単位が大きい変数だけが解析を支配し、重要度や類似度が測定単位で決まってしまう。
    • サンプル数に対して変数数・自由度が過大でないか
      なぜ必要？① 前提・入力妥当性で得られた結果が、解析上の仮定や偶然ではなくデータの実質的構造を反映しているか確認するため。誤ると未確認だと、手法の仕様や今回の標本が作った見かけの結果を、母集団に存在する真の現象として解釈する。

    ② 適合・情報保持

    モデルや低次元表現が元データをどの程度説明・再現しているか。

    • R²、deviance、残差、再構成誤差
      なぜ必要？モデルがデータの取り残し方を適切に表現できているか確認するため。誤ると仮定違反や未説明構造を無視し、係数・標準誤差・予測区間を実際より信頼できるものとみなす。
    • 寄与率、likelihood、AIC/BIC
      なぜ必要？要約・圧縮後の表現が元データの重要情報を失っていないか確認するため。誤ると失われた変動を無視した低次元表現を、現象全体の忠実な要約と誤認する。
    • 局所/大域構造の保存
      なぜ必要？低次元化や可視化で元空間の近傍・距離関係がどの程度保たれたか確認するため。誤ると描画上の近さ・島・間隔を、元データに存在する実際の距離や群構造だと誤認する。

    ③ 複雑さ・ハイパーパラメータ

    成分数・クラスタ数・正則化強度などを恣意的に決めていないか。

    • スクリープロット、parallel analysis
      なぜ必要？③ 複雑さ・ハイパーパラメータで得られた結果が、解析上の仮定や偶然ではなくデータの実質的構造を反映しているか確認するため。誤ると未確認だと、手法の仕様や今回の標本が作った見かけの結果を、母集団に存在する真の現象として解釈する。
    • CV、情報量規準、silhouette
      なぜ必要？モデル選択・チューニングに使った情報と性能評価を分離し、楽観バイアスを抑えるため。誤ると同じデータに最適化した性能を未知データの性能とみなし、精度を過大評価する。
    • 近傍数・距離・linkage等の感度分析
      なぜ必要？解析者が選んだ設定そのものが結論を作っていないか確認するため。誤ると特定設定でだけ成立する結果を、データ固有の真実であるかのように一般化する。

    ④ 解釈可能性・同定

    得られた軸・因子・係数・クラスタは科学的に意味があるか。

    • loadings / coefficients / prototypes
      なぜ必要？統計的検出の有無だけでなく、現象の大きさと不確実性を評価するため。誤ると小さく無意味な差を重要視したり、大きいが不確かな差を「差なし」と誤解する。
    • 符号・成分入替え・label switchingへの対応
      なぜ必要？④ 解釈可能性・同定で得られた結果が、解析上の仮定や偶然ではなくデータの実質的構造を反映しているか確認するため。誤ると未確認だと、手法の仕様や今回の標本が作った見かけの結果を、母集団に存在する真の現象として解釈する。
    • 既知の生理・臨床概念との整合
      なぜ必要？④ 解釈可能性・同定で得られた結果が、解析上の仮定や偶然ではなくデータの実質的構造を反映しているか確認するため。誤ると未確認だと、手法の仕様や今回の標本が作った見かけの結果を、母集団に存在する真の現象として解釈する。

    ⑤ 再現性・安定性

    標本や初期値を少し変えても同じ結論になるか。

    • bootstrap、subsampling、leave-one-out
      なぜ必要？推定結果が標本の偶然やアルゴリズムの初期条件に依存していないか確認するため。誤るとわずかなデータ変更で消えるパターンを、母集団に再現する安定した構造と誤認する。
    • random seed / 初期値反復
      なぜ必要？推定結果が標本の偶然やアルゴリズムの初期条件に依存していないか確認するため。誤るとわずかなデータ変更で消えるパターンを、母集団に再現する安定した構造と誤認する。
    • 係数・負荷量・所属・順位の分布
      なぜ必要？モデルがデータの取り残し方を適切に表現できているか確認するため。誤ると仮定違反や未説明構造を無視し、係数・標準誤差・予測区間を実際より信頼できるものとみなす。
    小標本では最重要。「点推定が出た」より「揺らしても残った」を重視。

    ⑥ 外的・下流妥当性

    別標本、別目的、臨床上の意思決定でも有用か。

    • external validation / temporal validation
      なぜ必要？別の集団・時期でも同じ関係が成立するかを確かめるため。誤ると今回の施設・症例・時期に固有の結果を、広い母集団へそのまま一般化する。
    • 分類・予測・群差などdownstream task
      なぜ必要？未知データにも同程度に機能するかを確かめるため。誤ると学習データへの適合を一般化性能と取り違え、将来症例での性能を過大評価する。
    • 感度分析、代替手法との一致
      なぜ必要？解析者が選んだ設定そのものが結論を作っていないか確認するため。誤ると特定設定でだけ成立する結果を、データ固有の真実であるかのように一般化する。

    ⑦ 不確実性・精度

    小標本

    点推定がどれほど揺れ得るかを明示する。

    • 区間推定：95%CI、bootstrap CI、prediction interval
      なぜ必要？同じ点推定でも標本が小さければ真値の候補範囲は大きく異なるため。誤ると点推定だけを見ると、偶然大きく出た推定値を精密な真値だと誤認する。
    • 推定分布：bootstrap分布、posterior、fold間分布
      なぜ必要？非対称・多峰性・裾の長さなど、標準誤差1個では見えない不確実性を確認するため。誤ると平均的なSEだけで安定して見せ、実際には符号反転や極端値が頻発する推定を確定的に扱う。
    • 小標本補正：exact法、t分布、small-sample df、cluster数補正
      なぜ必要？漸近近似が成立しにくい標本では通常の標準誤差やp値がずれるため。誤ると標本が少ないのに大標本近似を信じ、CIを狭くし偽陽性を増やす。

    ⑧ 欠測・選択プロセス

    誰が・どの値が解析に残ったかを妥当性の一部として扱う。

    • 欠測機序：MCAR/MAR/MNARの可能性、欠測パターン
      なぜ必要？欠測は値が消えただけでなく、解析対象の構成そのものを変えるため。誤ると欠測者を除外した集団だけの関係を、元の対象集団の真実と誤認する。
    • 解析対象の選択：除外、脱落、complete-case化の影響
      なぜ必要？解析に残る条件が曝露・アウトカムと関係すると選択バイアスが生じるため。誤ると選ばれた一部の症例で作られた関連を、全対象に一般化する。
    • 感度分析：欠測仮定や除外基準を変えた解析
      なぜ必要？観測不能な機序はデータだけでは完全に検証できず、仮定依存性を示す必要があるため。誤ると一つの都合のよい欠測仮定に依存する結論を、仮定に依らない事実として扱う。

    ⑨ 計算・実装妥当性

    数式が正しくても、アルゴリズムが正しい解に到達しているとは限らない。

    • 収束：optimizer/MCMC/EMの収束、gradient、warning
      なぜ必要？数値計算が途中の点や局所解で止まっていないか確認するため。誤ると未収束の数値を統計推定値とみなし、存在しない係数・クラスタ・posteriorを解釈する。
    • 初期値・seed：複数初期値、複数seed、再実行
      なぜ必要？非凸最適化や確率的アルゴリズムは開始点で結果が変わり得るため。誤るとたまたま良く見えた1回の解を唯一の真の解と誤認する。
    • 数値誤差：condition number、丸め誤差、step size、tolerance
      なぜ必要？悪条件問題では小さな入力誤差が巨大な出力差へ増幅されるため。誤ると測定ノイズや丸め誤差で生じた変化を、生理学的・統計学的な差として解釈する。

    ⑩ 仕様・分析者自由度への頑健性

    重要

    合理的な別仕様でも結論が残るかを確認する。

    • 前処理感度：標準化、filter、欠測処理、外れ値処理
      なぜ必要？前処理はデータそのものを変換し、結果の向きや大きさを決め得るため。誤ると特定の前処理でだけ現れるパターンを、現象そのものの構造と誤認する。
    • モデル仕様感度：変数、interaction、距離、link、分布、hyperparameter
      なぜ必要？複数の合理的仕様が存在するとき、1仕様だけではmodel uncertaintyを無視するため。誤ると研究者の選択で生じた結論を、データが一意に要求した結論のように見せる。
    • multiverse/specification curve：主要な合理的解析仕様を並べて結論の分布を見る
      なぜ必要？選択的な解析結果だけを採用する余地を可視化するため。誤ると最も都合のよい仕様だけを報告し、実際より頑健な知見に見せる。
    2. 小標本研究なら何を変えるべきか 添付ガイド原文

    結論：小標本では「有意か」より「どれだけ不安定か」を可視化する

    標本をtrain/testに単純分割すると、両方がさらに小さくなり推定が不安定です。予測モデルでは、全データを使いつつbootstrapでoptimismを補正する方法や、必要に応じてrepeated / nested cross-validationが合理的です。クラスタやPCAのような教師なし解析では、bootstrap/subsampling/leave-one-outで構造が再現するかを見ることが特に重要です。

    • 複雑さ制御：変数削減、正則化、自由度を抑える
      なぜ必要？モデルが標本固有ノイズへ過度に適合する自由度を抑えるため。誤ると偶然の微細パターンまで学習し、再現しない関係を真の構造として保持する。

    15. 実際の研究での妥当性評価フロー 添付ガイド原文

    解析法を問わず、この順番で考える

    問いを固定する

    説明・予測・分類・構造探索のどれが目的か。目的が違えば妥当性指標も変わる。

    ここを飛ばすと目的が曖昧だと、同じ数値を説明・予測・因果のどれにも都合よく読み替え、研究質問と結論がずれる。

    入力データの妥当性を確認

    測定信頼性、欠測、外れ値、尺度、独立性、標準化。

    ここを飛ばすと入力段階の測定誤差や依存を放置すると、その後どれほど高度なモデルでも歪んだ入力を精密に説明するだけになる。

    複雑さを決める

    成分数・cluster数・parameter数・λなどを、恣意的でなく決める。

    ここを飛ばすと自由度が多すぎるとノイズを構造化し、少なすぎると真の構造を潰す。

    fit / 情報保持を見る

    再構成、残差、内部指標、予測性能など手法固有のfit。

    ここを飛ばすと当てはまりの悪さや情報損失を無視すると、現象を十分表現していないモデルを真の構造とみなす。

    結果を解釈する

    loading、係数、cluster prototype、波形、臨床・生理学的意味。

    ここを飛ばすと数理的な軸・群・係数をそのまま生理概念へ置き換えると、意味の後付けが起こる。

    データを揺らす

    bootstrap / subsampling / leave-one-out / seed / parameter sensitivity。

    ここを飛ばすと少数例・seed・設定に依存する結果を、再現する母集団特性と取り違える。

    代替解析と比較

    別距離、別クラスタ法、別前処理、parametric/nonparametric等で結論の方向が残るか。

    ここを飛ばすと一つの手法でしか出ない結論を、手法依存ではなく現象依存と誤認する。

    不確実性込みで結論を書く

    「有意/非有意」ではなく、効果の大きさ・幅・安定性・どこまで一般化できるかを書く。

    ここを飛ばすと点推定やp値だけだと、効果の幅と不安定性が隠れ、結論の確実性を過大評価する。

    小標本の一文テンプレ

    「主解析の点推定に加えて、個々の症例への依存性と解析選択への依存性を評価し、再標本化・leave-one-out・感度分析で結論の安定性を検証する。」
